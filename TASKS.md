# TASKS

## Текущее

- Поддерживать цены, доступные форматы консультаций и FAQ в согласованном виде; у каждой карточки цены должна быть CTA записи с правильным форматом.
- После каждой правки сайта выполнять сборку, тесты и визуальную проверку.
- Публиковать проверенный `dist/` через workflow GitHub Actions и проверять успешный run перед завершением задачи.

## Контроль качества

- Не добавлять в коммиты `.env`, временные QA-файлы или чужие незакоммиченные изменения.
- Новые изображения, которые использует сайт, не являются «локальными»: они должны быть tracked в релизном commit. Нельзя публиковать ссылку на untracked asset.
- Перед финальным ответом закрывать все процессы и браузерные сессии, созданные для проверки.
