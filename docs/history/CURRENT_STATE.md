# CURRENT_STATE

Дата проверки: 2026-10-03.

- Сайт собран на React, TypeScript и Vite.
- Публичная поверхность: `https://sotnikova-psy.ru`.
- Исходная ветка: `gh-pages-source`; публикация выполняется workflow `.github/workflows/deploy-pages.yml`.
- Для видимых изменений обязательны локальная сборка, тесты, визуальная проверка и публикация в GitHub Pages.
- Runtime image/PDF/font/media, на которые ссылается сайт, должны быть tracked в том же commit. Статус «готово» возможен только после успешного workflow и свежей проверки живой страницы, включая новые assets.
- Локальные незакоммиченные файлы, не относящиеся к задаче, не должны попадать в релизный коммит.
- Раздел стоимости группирует обычную и диагностическую сессии внутри двух форматов встречи: онлайн и очно в Москве. Бесплатная встреча-знакомство показывается отдельной компактной плашкой; у каждой платной карточки одна общая кнопка записи на формат.
