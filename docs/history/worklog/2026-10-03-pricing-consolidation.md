# 2026-10-03 — компактная структура стоимости

Раздел стоимости перегруппирован по типу услуги. Бесплатная встреча-знакомство показывается отдельной компактной плашкой, а обычная и диагностическая сессии — двумя карточками. Внутри каждой карточки одновременно видны онлайн- и очный варианты с длительностью, ценой и отдельной кнопкой записи.

Цены, адрес очных встреч и пять сценариев попапа записи сохранены. Публикация считается подтверждённой только после локальной сборки и тестов, успешного workflow GitHub Pages и свежей проверки публичной страницы на мобильных и десктопных CSS viewport.
