# 2026-10-03 — стоимость по формату встречи

Раздел стоимости перегруппирован по формату встречи. В карточке «Онлайн» вместе показываются обычная сессия на 55 минут и диагностическая сессия на 90 минут. В карточке «Очно в Москве» вместе показываются обычная сессия на 50–55 минут и диагностическая сессия на 90 минут.

У каждой платной карточки одна общая кнопка записи на формат. Попап сообщает обе доступные длительности, а конкретный вид сессии уточняется в переписке. Бесплатная встреча-знакомство остаётся отдельной компактной плашкой.

Цены и место очных встреч не изменены. Публикация считается подтверждённой только после локальной сборки и тестов, успешного workflow GitHub Pages и свежей проверки публичной страницы на мобильных и десктопных CSS viewport.
