# DECISIONS

## 2026-10-03 — публикация GitHub Pages через Actions

Исходники сайта хранятся в `gh-pages-source`. GitHub Actions собирает `dist/` и публикует его в GitHub Pages как артефакт workflow. Это исключает ручные коммиты сгенерированного JavaScript в `gh-pages` и делает статус публикации проверяемым по run workflow. Домен остаётся настроенным в GitHub Pages; `public/CNAME` включается в собранный сайт.

## 2026-10-03 — жизненный цикл браузерной QA

Для визуальной проверки используется одна изолированная временная сессия без пользовательского профиля. После проверки она, локальный сервер и временные QA-артефакты закрываются и удаляются; вкладки пользователя не затрагиваются.
