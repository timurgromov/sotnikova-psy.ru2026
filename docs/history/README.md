# История проекта

Эта папка хранит только проверяемые сведения о текущем состоянии проекта, важных решениях и коротких рабочих записях. Она не заменяет исходники и не содержит секретов или временных артефактов.

- `CURRENT_STATE.md` — актуальные подтверждённые факты.
- `DECISIONS.md` — решения, влияющие на поддержку и релизы.
- `RETROSPECTIVE_BOOTSTRAP.md` — исходная точка документации.
- `worklog/` — короткие записи о существенных изменениях.
